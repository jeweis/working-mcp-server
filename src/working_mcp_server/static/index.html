首次连接指南

还有几步需要你完成

  1. 在 Platform 创建 Tunnel

    选择正确的组织，创建或复用隧道，并关联准备用来添加插件的 ChatGPT 工作区。复制 Tunnel ID 填入左侧。

  2. 创建运行密钥并授权

    创建具有 Tunnels Read + Use 权限的运行 API Key，填入左侧。创建、修改隧道需要 Read + Manage。权限属于组织，添加自定义 MCP 的权限由 ChatGPT 工作区另外控制。

  3. 启动并检查就绪状态

    保存配置并启动，等待「隧道就绪」。本应用会在本机转发时附加 MCP API Key，你无需把 wmcp_... 密钥填到 Tunnel 运行密钥中。

  4. 在 ChatGPT 添加自定义 MCP

    Plugins → ＋ → Add custom MCP server。名称填 Working MCP，Connection 选 Tunnel，选择或粘贴 你的 Tunnel ID。Authentication 选择 No authentication，审阅页面提示后创建插件并安装。

  5. 调用工具，完成最终验证

    在 ChatGPT 选择 Working MCP 插件，调用 workspace_current。客户端就绪仅代表本机连接状态，工具调用成功才完成端到端验证。

隧道看不到或连接失败？

确认 Tunnel 关联的是当前 ChatGPT 工作区，操作人和运行密钥具有 Read + Use，并允许本机向 api.openai.com:443 发起 HTTPS。新权限可能需要最多 30 分钟生效。企业工作区关联失败时需联系 OpenAI 客户团队。

隧道提供私人连接，不支持作为公开插件提交的公网端点。详情以官方指南和账号实际权限为准。
